# V12 — Benchmarking / Marketplace / Platform Ecosystem

## Objective
Create network effects and a differentiated data/intelligence layer.

## Benchmarking
Compare client performance against:
- industry
- business size
- geography where appropriate
- anonymised peer groups.

Metrics:
- gross margin
- net margin
- debtor days
- creditor days
- payroll ratio
- rent ratio
- operating expense ratio
- growth.

## Privacy
Benchmarking must use aggregation and anonymisation controls.
No client-identifiable information is exposed.

## Industry Intelligence
Create sector models for:
- restaurants
- retail
- professional services
- construction
- property
- e-commerce
- healthcare
- technology.

## Accountant Marketplace
Potential ecosystem:
- integrations
- templates
- workflows
- AI agents
- specialist reports
- advisory packs.

## API Platform

Accounting data
